Stakeout flow (checkbox by default - no per-station taping): ⓪ indoors: tape 5 flags on each of the 7 train cords @ 12/66/120/174/228 in, measured from the cord's wall-A zero mark under deployment tension (measure once - all cords identical) ① on site: tape each cord's x from the corners along BOTH long walls, mark the wall ends (table below) ② stretch the cord taut at soil level, wall-A zero mark at the wall face, cones weighting both ends ③ place the board: 54 cm short edge hugging the cord, origin corner at the flag, +x arrow toward the far end (A4) → position + orientation aligned in one motion → checkbox ④ only a board that cannot land at its flag (obstruction) gets moved and hand-measured (the * column) ⑤ do not block any camera's line of sight to the board (step 2-3 m aside; being in frame is harmless), hold 8-10 s. Only cross-width cords are used - flags carry y, so length-wise cords add nothing. IDs are paper bookkeeping only (T34 = cord 3, flag 4); no ID marks on the field, cameras never need to see them - identification = time + order + position self-consistency. Cones: weight cord ends + mark upcoming stations for wayfinding; never a precision datum (a cone base is ±several cm ambiguous). Iron rules: exactly ONE board on the field at any time · everything matte, NO retroreflective tape (glare / IR blooming kills nearby corner detection) · SEAM rows are placed after checking preflight stills · call remote QC after each batch before continuing · before leaving: wait for _to_ closure, verify + back up · ground stations serve CH03/04 too (all cameras record together).
